滚轮区域

01 / 滚轮区域

在屏幕边缘，滚动即操作

将鼠标移到屏幕角落或边缘，再滚动滚轮执行动作。每个区域都能分别设置向上和向下滚动的动作。

选择触发区域
点击周围的区域开始设置

角落优先于相邻的边缘；同一套区域设置适用于所有显示器。

正在设置

左上角

连续滚动时同一区域、同一滚动方向的两次触发之间会稍作等待，避免一个滚轮手势重复执行动作。间隔可在通用设置中调整。
02 / 快捷键

一按就能执行常用动作

录制组合键、选择动作并保存。窗口隐藏时仍可使用；暂停功能后快捷键也会停用。

还没有快捷键添加快捷键，选择常用动作，保存后即可使用。
03 / 插件

用插件添加更多动作

将插件放入插件目录，启用并保存后，就能在滚轮区域和快捷键中选择它提供的动作。

开发自己的动作插件
PLUGIN API V1

在插件目录中新建文件夹，放入 plugin.json 和入口 JS 文件。启用插件并保存后，新动作就会出现在动作列表中。

exports.activate = (api) => {
  return api.registerAction({
    id: 'hello',
    name: '显示问候',
    run: ({ source }) => api.notify('Hello', source)
  });
};

完整的清单格式与 API 文档见项目中的 docs/plugin-api.md。

了解 Linux 桌面兼容方式

X11：通过全局输入钩子监听滚轮，动作使用 wmctrl/xdotool。
Wayland：Slipy 在已配置的屏幕边缘放置透明悬浮条来接收滚轮事件；动作优先走桌面环境的原生接口——KDE 与 GNOME 使用 DBus，Hyprland 使用 hyprctl，Sway 使用 swaymsg，其余情况可安装 ydotool（需启用 ydotoold 服务）作为通用兜底。

媒体、音量和亮度动作分别需要 playerctl、wpctl/pactl、brightnessctl，与显示服务器无关。
